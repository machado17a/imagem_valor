📰 Extrator de Matérias

Instalar no Safari iOS — Formata matérias para WhatsApp

Recomendado · Auto-atualiza
Via app Atalhos — 2 ações

Instala uma vez. Quando o código mudar, o atalho já pega a versão nova automaticamente.

1

Copiar a URL do script

Toque no botão abaixo para copiar o endereço do script.

2

1ª ação: Obter conteúdo da URL

Abra o app Atalhos → toque em +.

Toque em "Adicionar ação" → pesquise "Obter conteúdo da URL" → selecione-a.

Toque no campo URL dentro da ação → Cole a URL copiada no passo 1.

3

2ª ação: Executar JavaScript

Abaixo da 1ª ação, toque em "+" ou "Adicionar ação" → pesquise "Executar JavaScript" → selecione "Executar JavaScript na Página Web".

Toque no campo Script → selecione tudo e apague.

Toque e segure o campo vazio → toque em "Inserir Variável" → selecione "Conteúdo da página" (resultado da 1ª ação).

4

Nomear e ativar na Folha de Compartilhamento

Toque no nome no topo → "Renomear" → digite Extrator WhatsApp → OK.

Na barra inferior, toque no ícone (i) → ative "Mostrar ao Compartilhar" → toque em Concluído.

✓ Como usar

Abra qualquer matéria no Safari → toque em Compartilhar (⬆️) → role a lista e toque em "Extrator WhatsApp".

O painel com o texto formatado aparecerá para copiar e colar no WhatsApp.

Atualização: automática — nada a fazer quando o código mudar.

3

4

Método Alternativo — Bookmarklet
Via Favorito (Bookmarklet)

Pode não funcionar em algumas versões do iOS 17/18

1

Copiar o código do bookmarklet

Toque no botão abaixo para copiar o código.

2

Salvar qualquer favorito no Safari

Toque em Compartilhar (⬆️) → "Adicionar aos Favoritos" → Salvar (qualquer nome por enquanto).

3

Editar o favorito e colar o código na URL

Toque no ícone do Livro → encontre o favorito salvo → toque e segure → "Editar".

Toque no campo URL → selecione tudo → Cole o código copiado no passo 1.

Mude o nome para Extrator WhatsApp → OK → Concluído.

4

Como usar

Abra a matéria no Safari → toque na barra de endereço → digite "Extrator" → selecione o favorito na lista.
